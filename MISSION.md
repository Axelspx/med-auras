# Mission: Build the Medication Cooldown Widget in C++

## Why
Build the lightweight medication timer described in `README.md` and `AGENTS.md`, while gaining enough C++ context to understand the examples and follow the project's development.

## Success looks like
- Configure and build a C++20 CMake project in a JetBrains IDE.
- Recognize the basic roles of C++, CMake, MSVC, and Win32 in this project.
- Follow concise explanations of new code and make small changes from examples.
- Understand the visible behavior produced by each project milestone.

## Constraints
- This is the learner's first C++ project.
- Use native C++20, Win32, CMake, and the existing Microsoft toolchain.
- Keep explanations short, practical, and tied to code being added to the real application.
- The agent should implement the project while explaining only the fundamentals needed to follow the current change.
- Do not turn project work into a comprehensive or theory-heavy C++ course.

## Out of scope
- In-depth study of C++, the C++ standard, advanced language features, or language theory.
- Standalone exercises that do not directly help build or understand the medication widget.
- Learning unrelated C++ frameworks or cross-platform GUI libraries.
- Building non-MVP features before the core widget works.
