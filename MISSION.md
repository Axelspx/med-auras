# Mission: Build the Medication Cooldown Widget in C++

## Why
Learn enough modern C++ and native Windows development to build, understand, and maintain the lightweight medication timer described in `README.md` and `AGENTS.md`.

## Success looks like
- Configure and build a C++20 CMake project in a JetBrains IDE.
- Read, modify, run, and debug the native Win32 application with confidence.
- Preserve the project's event-driven, low-resource design while adding MVP features.

## Constraints
- This is the learner's first C++ project.
- Use native C++20, Win32, CMake, and the existing Microsoft toolchain.
- Keep lessons short and tied to the next working piece of the real application.

## Out of scope
- Learning unrelated C++ frameworks or cross-platform GUI libraries.
- Building non-MVP features before the core widget works.
