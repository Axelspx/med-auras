Connect a C++ IDE to your Windows compiler

Tangible win: finish with CLion able to detect the Microsoft compiler and CMake already installed on this computer.

Important: IntelliJ IDEA and CLion look similar because both are JetBrains IDEs, but JetBrains does not officially support C++ in IntelliJ IDEA. Use CLion for this repository.

The three pieces

  • CLion is the editor, project view, Run button, and debugger.
  • MSVC is the compiler that translates C++ into a Windows executable.
  • CMake reads CMakeLists.txt and tells MSVC which files and Windows libraries belong to the executable.

This PC already has Visual Studio Build Tools 2026, its C++ workload, the 64-bit compiler environment, and CMake 4.1.1. MSVC often does not appear in a normal terminal's PATH; CLion initializes it through Visual Studio's environment script.

Do this now

  1. Install CLion, preferably through JetBrains Toolbox if you already use it. You do not need to uninstall IntelliJ IDEA.
  2. Start CLion and open C:\Users\axels\Documents\IntelliJ\med-auras.
  3. Open File → Settings → Build, Execution, Deployment → Toolchains.
  4. Add or select Visual Studio. Choose the detected Visual Studio Build Tools 2026 installation and set Architecture to amd64.
  5. Confirm that C compiler, C++ compiler, debugger, CMake, and build tool show successful detection rather than red errors.
  6. Click Apply, then OK.

What happens next

The repository currently has requirements documents but no CMakeLists.txt or src/main.cpp. That is expected: the next lesson will add the smallest buildable C++20 Win32 application. Once those files exist, CLion will load the CMake target and show Run and Debug controls.

Self-check: explain aloud which tool edits the code, which tool compiles it, and which file describes the build. If you can answer “CLion, MSVC, and CMakeLists.txt,” the mental model is in place.
