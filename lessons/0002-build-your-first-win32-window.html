Medication Cooldown Widget · Lesson 2

Build and run your first native window

Tangible win: click Run in CLion and see a Windows application built from this repository.

What was added

  • CMakeLists.txt is the build recipe. It creates one C++20 Windows executable named med-auras.
  • src/main.cpp registers a window type, creates one window, and waits for Windows messages.

Do this in CLion

  1. Return to CLion. If it does not load the new file automatically, choose Tools → CMake → Reload CMake Project.
  2. Wait until indexing and CMake configuration finish. The target selector near the top should say med-auras.
  3. Click the green Run triangle, or press Shift+F10.
  4. A plain window titled Medication Cooldown Widget should appear. Close it with the normal X button.

The mental model

CMakeLists.txt → MSVC compiler → med-auras.exe
                                      ↓
                           Windows sends messages
                                      ↓
                         window_procedure handles them

The GetMessage call waits efficiently until Windows has something to report. It is not a continuously running polling loop, so it fits the project's near-zero idle CPU requirement.

Try the debugger once

  1. Open src/main.cpp.
  2. Click the gutter beside ShowWindow(window, show_command); to create a red breakpoint.
  3. Click the bug-shaped Debug button, or press Shift+F9.
  4. When execution pauses, inspect the window variable, then click Resume.
  5. Remove the breakpoint by clicking it again.
