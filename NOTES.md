# Teaching Preferences

- The learner does not currently want an in-depth C++ education.
- Project delivery comes first: the agent should continue implementing the medication widget.
- Explain basic fundamentals briefly and in context as relevant code is introduced.
- Prefer concrete examples from this repository over abstract lessons or unrelated exercises.
- Give the learner enough information to understand what changed, why it exists, and how to run or verify it.
- Offer deeper explanations only when requested.
