# C++ and Win32 Project Resources

## Knowledge

- [CLion: Configure a toolchain](https://www.jetbrains.com/help/clion/how-to-create-toolchain-in-clion.html)
  Official reference for connecting CLion to CMake, a compiler, a build tool, and a debugger.
- [CLion: Configure CLion on Windows](https://www.jetbrains.com/help/clion/quick-tutorial-on-configuring-clion-on-windows.html)
  Official Windows walkthrough, including the Microsoft Visual C++ toolchain used by this project.
- [Microsoft: Visual Studio Build Tools C++ workload](https://learn.microsoft.com/en-us/visualstudio/install/workload-component-id-vs-build-tools?view=visualstudio)
  Authoritative list of the compiler, Windows SDK, CMake, and related components required for native C++ builds.
- [Microsoft: Walkthrough—create a traditional Windows desktop application](https://learn.microsoft.com/en-us/cpp/windows/walkthrough-creating-windows-desktop-applications-cpp)
  Primary introduction to the Win32 application and message-loop structure this widget will use.
- [CMake tutorial](https://cmake.org/cmake/help/latest/guide/tutorial/)
  Official explanation of how `CMakeLists.txt` turns source files into build targets.

## Wisdom (Communities)

- [C++ Help on Stack Overflow](https://stackoverflow.com/questions/tagged/c%2b%2b)
  Useful for narrowly scoped compiler or language questions; prefer answers that cite the standard or official documentation.
- [Microsoft Q&A: Windows API](https://learn.microsoft.com/en-us/answers/tags/224/windows-api-win32)
  Appropriate for concrete Win32 API and Windows SDK problems.
